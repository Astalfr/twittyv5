# Testing

**Goal: Twitter can change under us and we can refactor freely without breaking features.** Every feature is covered by an automated test on the layer where it lives, and a change isn't finished until all checks pass.

## Definition of done

1. Tests for the new or changed behaviour are added in the same change. A bug fix starts with a failing test.
2. `cargo fmt --all`
3. `cargo clippy --workspace --all-targets -- -D warnings`
4. `cargo test --workspace`
5. Snapshot changes are reviewed with `cargo insta review` and explained in the commit message.
6. The matching `docs/` page is updated.

Never `#[ignore]`, weaken or delete a test to get a green run.

## Manual check

With a session (see "Signing in" in [x-api.md](x-api.md)), `cargo run -p twitty` shows real timelines; the log says `signed in as @handle`. Without one it shows the deck on demo data. New demo tweets arrive every 20s and columns poll every 30s. After about a minute, a column scrolled away from the top shows the "N new tweets" pill.

## Fixtures

- These live in `crates/twitty-x/tests/fixtures/<name>.json` and **must be anonymised** with `twitty-x-cli anonymise` (see [x-api.md](x-api.md#capturing-a-fixture)). Current set: `home`, `home--latest`, `usertweets-elonmusk`, `usertweets-nasa`, `search-quotes`, `search-videos`, `search-rust`, `tweetdetail`, `notifications`, `userreplies-nasa`, `usermedia-nasa`, `usermedia-nasa-2`, `list-space`, `search-translated` (Japanese search with Grok translations), `tweetdetail-note` (a conversation whose focal tweet has a Community Note), `search-people` (the People tab of a search: accounts only, translated by `translate::users` and snapshotted separately).
- Minimum cases, kept up to date:
  - plain tweet, reply, self-thread module, retweet, quote
  - quote of a deleted tweet, long `note_tweet`, Grok translation, Community Note (`birdwatch_pivot`) with a link
  - 1/2/3/4 photos, video, GIF, poll, link card
  - tombstone, withheld, `TweetWithVisibilityResults`
  - pinned entry, promoted entry (dropped), top/bottom cursors, empty timeline
  - emoji/RTL/CJK text with entities.
- When Twitter changes, **add** a new fixture (e.g. `retweet_2026-11.json`) and keep the old ones. Old shapes must keep translating if Twitter still sends them anywhere.

## Snapshot policy

- Snapshots are of **model output**, never raw JSON. They're stable, readable and diffable.
- A snapshot diff on an existing fixture is a behaviour change. It must be intended and explained in the commit message.

## Test style

- Name tests `<unit>_<scenario>_<expected>`, e.g. `translate_retweet_unwraps_original_author`.
- Tests return `Result<(), Box<dyn Error>>` and use `?`. Asserts must carry useful messages.
- No network, no sleeping, and no wall clock in tests. Inject a `Clock` and use `tokio::time::pause` for backoff tests.
- Every bug found in production gets a test named after the symptom.

## Coverage

`cargo llvm-cov --workspace --html` (requires `cargo install cargo-llvm-cov`).
- Target **≥ 90%** line coverage for `twitty-x::translate`, `wire` and `transport`, and ≥ 80% across the workspace (excluding view rendering code).
- Coverage is a guide, not the goal. Behaviour tests come first.
